# NeuController Desktop (Electron)

Modern neumorphic desktop companion app for NeuController.

## Features
- **One-Click Server**: Start/Stop the Python virtual gamepad server without touching the terminal.
- **IP Display**: Prominently shows active laptop IP addresses with a 1-click copy button.
- **Live Controller Visualizer**: Real-time PlayStation DualShock/DualSense visualizer reflecting button presses, stick movements, and trigger pressure from the mobile app at 60 Hz.
- **System Tray**: Minimize to the system tray while gaming.
- **Light & Dark Theme**: Sleek neumorphic design matching the mobile app.

## Quick Start

```bash
cd electron
npm install
npm start
```
